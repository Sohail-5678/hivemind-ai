HiveMind, in pictures

HiveMind lets a whole team share one live AI-agent session: everyone watches the same stream, and anyone can redirect, pause, resume, stop or fork the agent while it is running. It runs as a Node server with WebSocket rooms and SQLite, or as a zero-backend static site where browser tabs sync through BroadcastChannel.

The real-world problem, and how it's solved

AI agents are still used alone, in a box only one person can see. HiveMind turns the agent session itself into the shared thing.

What happens when a teammate sends a message

One message travels through validation, the shared timeline and the room before it ever reaches a model. The agent only starts when the room is idle, and a failing model never stops the flow.

Redirecting an agent mid-stream

A redirect does not wait for the agent to finish. The running stream is aborted with a reason, what it wrote is kept and labelled, and a follow-up run starts in the same tick. If a human pauses in the gap, the pause wins.

When the model API misbehaves

A model server can refuse, hang, or answer with an empty body that looks like success. Each case is detected and the run falls back to the built-in agent with a visible notice, so the room never dead-ends.

Two runtimes, one protocol

The same client bundle runs against a Node server or with no backend at all. Both transports emit identical messages, so the reducer, timeline, presence bar and composer are shared verbatim.
